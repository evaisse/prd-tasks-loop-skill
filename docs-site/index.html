PRD Tasks Loop

Visible delivery loops for story-scoped coding agents.

Author a canonical PRD, pick the next actionable user story, render one bounded prompt, and let the loop verify the PRD update, commit discipline, and runtime cleanup.

View repository Open the skill
Loop Snapshot story-by-story
  1. Validate one PRD under docs/prd/
  2. Resolve the next unblocked US-xxx
  3. Render a focused agent prompt with tests and gates
  4. Require a PRD update and Git commit proof on success
  5. Retry, back off, or stop with visible logs on failure
What It Ships

Canonical PRD format

Predictable Markdown structure, stable identifiers, and explicit user stories ready for execution.

Observable runtime

State and progress logs sit beside the PRD while the story is in flight, then disappear on completion.

Commit discipline

Successful stories can require conventional commits that reference both the user story and the attached PRD.

Contract

One story in, one accountable change out.

The runner sends a single active story, current acceptance criteria, TDD hints, quality gates, and runtime context. Agents are asked to finish exactly that slice, update the PRD, and leave behind an auditable commit trail.

Flow

From PRD to shipped slice.

01

Write the PRD

Keep stories explicit, dependency-aware, and TDD-oriented.

02

Run the loop

Pick a preset or custom agent command and confirm the execution set.

03

Verify the outcome

Require PRD checkbox progress, optional commit proof, and log cleanup.
