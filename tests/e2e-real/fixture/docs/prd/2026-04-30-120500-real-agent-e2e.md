# PRD: Real agent CLI E2E smoke test

## Introduction/Overview
This PRD validates that a real agent CLI can execute one bounded story through the loop runner in a clean Git repository.

## Goals
- Verify the loop can invoke a real CLI non-interactively.
- Verify the agent can read the rendered prompt and update the repository.
- Verify the story completes with a Git commit and runtime log cleanup.

## User Stories
### US-001: Complete the bounded smoke-test story
**Description:** As a maintainer, I want a real agent CLI to complete a tiny deterministic task so that I can smoke-test the full loop in CI.

**Acceptance Criteria:**
- [ ] The file `project/result.txt` exists and contains exactly `STATUS=done`
- [ ] The current story acceptance criteria are checked in the PRD
- [ ] A Git commit is created for the story

**TDD Plan:**
- Test: Verify `project/result.txt` contains the exact expected content and the PRD checkboxes were advanced.
- Implementation: Create or overwrite `project/result.txt`, update the PRD checkboxes, then commit the story-scoped changes.

**Dependencies:** -
**Parallel Group:** e2e

## Functional Requirements
- Modify only `project/result.txt` and the current PRD file.
- Write exactly `STATUS=done` followed by a trailing newline to `project/result.txt`.
- Check all acceptance criteria for the active story before exiting successfully.
- Create exactly one story commit after updating the files.

## Non-Goals
- Solving an open-ended coding problem.
- Performing network calls other than the configured model provider.

## Success Metrics
- The loop exits with status code 0.
- The fixture repository has exactly two commits after the run.
- The runtime log files are removed after successful completion.

## Open Questions
- None.

## Execution Settings
Test Command: python3 -c "from pathlib import Path; import sys; sys.exit(0 if Path('project/result.txt').read_text(encoding='utf-8') == 'STATUS=done\n' else 1)"
Quality Gates:
- git diff --exit-code
